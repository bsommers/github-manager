# Git Manager Admin Console (GMAC)

This is:

- a github manager 
- with MCP server 

## Problems it solves
- managing several, dozens, hundreds of repos by humans and AI Agents
- need central registry
- need coordination
- need to tame complexity

## Functions:

- it lets me look at my repos 
- can access a list / set of (multiple users, multiple orgs) 
- and track and manage PRs, reviews, etc. 
- can run from anywhere - AI agents, web-APIs, MCP clients/servers, cli, user's desktop, and so on. the universe is the limit
